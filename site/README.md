# Boxtown site

The landing page at <https://byronwall.github.io/boxtown/>. It is static: `site/public/` is the whole site, with no build step. `.github/workflows/pages.yml` deploys it when `site/public/` changes on `main`.

## Files

- `public/index.html`, `public/site.css`, `public/site.js`: the page, its styles (tokens from `DESIGN.md`), and the tabs, copy buttons and lightbox.
- `public/town-map.js`, `public/town-ui.js`, `public/town.css`: the live map. It draws the demo in SVG from `public/demo/town.json` and runs the hero explorer, the scroll story and the agent terminal.
- `public/demo/`: generated by `scripts/export-demo.mjs`. It holds the nodes, links, node images, real CLI output, and the box positions that the app itself computed at each depth and for each isolated branch.
- `public/images/*.webp`: screenshots of the fictional Harbor Bikes demo. Captured at 1440 × 900, 2× scale.
- `public/llms.txt`: the short version for agents.
- `public/og.png`, `public/apple-touch-icon.png`: written by the check script with `--og`.
- `scripts/seed-demo.mjs`: builds the Harbor Bikes project through the `boxtown` CLI.
- `scripts/capture.mjs`: seeds a fresh demo in `tmp/site/demo-data`, starts the packaged viewer on it, writes the screenshots, then exports `public/demo/`.
- `scripts/check-site.mjs`: checks the page under `/boxtown/` and writes review screenshots to `tmp/site/shots/`.

## Reshoot the screenshots

From the repo root (about 1 minute after the first build):

```bash
pnpm install
pnpm cli:prepare-package
pnpm --dir site capture
```

`cli:prepare-package` builds the app into the CLI. Run it again after app changes. Playwright is pinned to 1.58.0, which uses the cached `chromium_headless_shell-1208`; run `pnpm --dir site exec playwright install chromium` if it is missing.

Box positions in the live map come from the app's canvas, so an app layout change shows up after a reshoot. The camera and selection for each screenshot come from URL parameters in `capture.mjs` (`node`, `view`, `isolate`, `edges`, `inspector`). Check each image after a reshoot: the layout can move when the app changes.

## Check the page

```bash
pnpm --dir site check
```

The script serves `site/public` under `/boxtown/` on a free port, so no other server is needed. Add `--og` to rewrite `og.png` and `apple-touch-icon.png`. Pass a URL to check a running site instead. The `Site check` workflow runs it on every PR and on `main`.

The checks cover sideways scroll at 1440, 1100, 800 and 390 px, failed requests and console errors, every image, link and anchor, the tab keys and `#tour/<id>` deep links, the copy button, and the lightbox.
